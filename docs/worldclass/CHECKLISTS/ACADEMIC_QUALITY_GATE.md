# Academic Quality Gate

Her akademik engine/report değişikliğinde doldurulur.

## Belge/çalışma türü

- [ ] Output document_type’a göre değişiyor.
- [ ] Output study_design’a göre değişiyor.
- [ ] Unknown/low confidence durumunda güvenli fallback var ve kullanıcıya açık.

## Evidence

- [ ] High-severity finding manuscript anchor taşıyor.
- [ ] Citation/evidence support level var.
- [ ] Confidence ve limitation dolu.
- [ ] Kaynak uydurma yok.

## Actionability

- [ ] Critical/major finding action item taşıyor.
- [ ] Action item target_section, effort, expected_gain içeriyor.
- [ ] Öneri generic değil uygulanabilir.

## Rubric/guideline

- [ ] Rubric id/version provenance’a yazılıyor.
- [ ] Guideline applicable/not-applicable/degraded durumları açık.
- [ ] Nitel/nicel özel boyutlar korunuyor.

## Eval

- [ ] Fixture veya goldset güncellendi.
- [ ] Eval metrics bozulmadı.
- [ ] Schema validation %100.

## Son karar

- [ ] Gate passed.
- [ ] Gate failed; task incomplete.
