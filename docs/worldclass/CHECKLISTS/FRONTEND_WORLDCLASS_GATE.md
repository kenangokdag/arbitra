# Frontend World-Class Gate

A frontend phase cannot be marked complete unless all applicable gates pass.

## Landing gate

- [ ] H1 communicates “review-before-reviewer” promise.
- [ ] Primary CTA starts review.
- [ ] Secondary CTA opens sample report.
- [ ] Use cases include article, conference, thesis, grant.
- [ ] Confidentiality-first block appears before final CTA.
- [ ] Chatbot vs Arbitra comparison is capability-based, not hype.
- [ ] No fake testimonials, fake metrics or unsupported security claims.
- [ ] Mobile first fold has visible CTA.

## Wizard gate

- [ ] Five-step flow exists: file, document type, target, privacy, depth.
- [ ] Beginner path works with “Arbitra seçsin”.
- [ ] Expert drawer exposes advanced controls where supported.
- [ ] Privacy step is non-skippable.
- [ ] Confidential reviewer/editor mode defaults external AI to blocked.
- [ ] Backend receives consent/privacy metadata.
- [ ] Errors map to useful field-level messages.

## Live cockpit gate

- [ ] No spinner-only waiting state.
- [ ] Stage timeline renders real statuses.
- [ ] Detected manuscript profile appears when available.
- [ ] Degraded notices are visible and honest.
- [ ] Failed stages show retry/cancel/support path.

## Report gate

- [ ] ReportView uses typed report sections, not one giant string blob.
- [ ] Verdict header appears first.
- [ ] Top fatal risks are visible above long detail.
- [ ] Risk radar exists.
- [ ] Reviewer council exists.
- [ ] Evidence map exists.
- [ ] Action plan exists.
- [ ] Every high-severity finding has anchor, confidence, evidence/provenance and action.
- [ ] Abstract-only/unresolved evidence is visually distinct.
- [ ] Drawers are accessible.

## Revision/export gate

- [ ] P0/P1/P2 action board/list exists.
- [ ] Filters exist for section, effort, expected gain and status.
- [ ] Export UI is authz-aware.
- [ ] Confidentiality disclosure can be included where relevant.

## Accessibility gate

- [ ] One H1 per page.
- [ ] Proper landmarks.
- [ ] Visible focus states.
- [ ] Keyboard wizard completion.
- [ ] Drawer focus trap and Escape close.
- [ ] Color is not the only severity signal.
- [ ] Long report has section navigation.

## Quality gate

- [ ] Typecheck passes.
- [ ] Lint passes or known existing failures documented.
- [ ] Critical E2E journeys pass or are added as pending with explicit blocker.
- [ ] No production placeholder/mock UI in critical paths.
- [ ] STATE.md updated.
