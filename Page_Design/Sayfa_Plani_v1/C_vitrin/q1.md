**Mevcut bileşenleri yeniden kullan:**

### Backend

**Yeni endpoint: `POST /api/q/literature`**

Request:

```python
class QLiteratureRequest(BaseModel):
    model_config = ConfigDict(extra="forbid")
    query_id: str = Field(min_length=8, max_length=64)
```

Response:

```python
class QLiteratureResponse(BaseModel):
    model_config = ConfigDict(extra="forbid")
    query_id: str
    language: Literal["tr", "en", "id"]      # sorgu dili (Q'dan miras)
    sol_panel_papers: list[PaperCard]        # 3 kart, hem Anon hem Pro
    paywall: bool                            # Anon → True, Pro → False
    summary_text: str | None                 # Pro: ~400 kelime, sorgu dilinde
    citations: list[CitationMap] | None      # Pro: cümle → paper map
    used_paper_ids: list[str] | None         # Pro: K=12 paper id (rank "01".."12")

class CitationMap(BaseModel):
    model_config = ConfigDict(extra="forbid")
    sentence_idx: int                        # 0-based özetteki cümle indeksi
    paper_ids: list[str]                     # ["01", "03"] gibi rank-string
```

`PaperCard` Q sayfası ile **aynı schema** (DM-047/052 — `card_summary` + `card_lang` field'ları sorgu dilinde).

**Service:** `api/services/q_literature_service.py` (yeni)

1. `query_id` ile Redis'ten Q havuzunu çağır: `q:search:{sha256(query)}:{lang}` (Q'da yazıldı). Miss → HTTP 410 Gone, frontend `/q`'a yönlendirir.
2. Tier check: HTTP cookie `pm_tier` (pilot için) → `"anon"` | `"pro"`. F2'de Supabase session.
3. **Anon path:**
   - Cache `q:literature:{query_id}:anon` hit → return
   - `sol_panel_papers` = havuzdan rank 1..3 (50-paper havuz Q'da sıralı)
   - `paywall=True`, `summary_text=None`, `citations=None`, `used_paper_ids=None`
   - Cache yaz, 24h TTL
4. **Pro path:**
   - Cache `q:literature:{query_id}:pro` hit → return
   - **Rerank Aşama 1 (deterministic):** 50-paper havuzdan native skor (S2 `relevance` + TRDizin native order) → top-25
   - **Rerank Aşama 2 (LLM):** Gemini Flash 2.0 → 25 paper'ı sorguya göre yeniden sırala. Pydantic structured output:
     ```python
     class RerankOutput(BaseModel):
         ordered_paper_ids: list[str] = Field(min_length=25, max_length=25)
     ```
   - K=12 üstten al → `used_paper_ids`
   - **Özet üretimi:** Gemini Flash 2.0, prompt sorgu diline göre seçilir:
     - `lang=="tr"` → "Aşağıdaki K akademik makale abstract'ından **Türkçe** ~400 kelime literatür özeti yaz. Her cümle bir veya birden çok paper'a dayanmalı; cümle sonunda `[01]`/`[02]`/.../`[12]` rank-alıntısı koy. Halüsinasyon yasak."
     - `lang=="en"` → "Write a ~400-word academic literature summary in **English** from the K abstracts below. Each sentence must be grounded in one or more papers; cite with `[01]`..`[12]` rank tags. No hallucination."
     - `lang=="id"` → "Tulis ringkasan literatur akademik ~400 kata dalam **Bahasa Indonesia** dari K abstrak di bawah. Setiap kalimat harus didukung satu atau lebih paper; sitasi `[01]`..`[12]`. Dilarang halusinasi."
   - **Pydantic structured output (citation grounding kapısı):**
     ```python
     class LiteratureSummary(BaseModel):
         summary_text: str = Field(min_length=200, max_length=4000)
         citations: list[CitationMap] = Field(min_length=1)
         used_paper_ids: list[str] = Field(min_length=12, max_length=12)
     ```
   - Validation: her `citations[i].paper_ids` ⊆ `used_paper_ids` olmalı (sınır dışı rank → reject + 1 retry).
   - `sol_panel_papers` = havuzdan rank 1..3 (Anon ile aynı)
   - Cache yaz, 24h TTL

**LLM seçimi:**

- Pilot: tek model **Gemini Flash 2.0** (DM-049 hybrid rerank Aşama 2 + özet üretimi). Multi-language native destek (TR/EN/ID hepsinde competent).
- F2'de değerlendirme: Cosmos (TR) / Qwen2.5 (EN) / Sea-Lion (ID) ayrı stack hem maliyet hem kalite açısından — pilot 5 user verisi sonrası karar.

**Diğer endpoint'ler:**

- `POST /api/waitlist` — Q ile aynı endpoint, `query_id` field'ı `qid`'i taşır.
