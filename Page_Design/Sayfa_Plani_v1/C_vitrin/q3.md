## ROL

Vitrin funnel'in **eylem önerisi ekranı**. Q'dan gelen sorgu için **metodolojik danışmanlık** üretir. Sayfa herkese açık; içerik tier'a göre değişir:

- **Anon:** Sol panel 3 kart + sağda paywall placeholder + capture form (Q1 ile simetri)
- **Pro:** Sol panel 3 kart + sağda **3 komponent** (DM-055):
  - (a) **Metod dağılımı** (% bazında, 25-paper üzerinde)
  - (b) **2-3 metod önerisi** (sorguya uygun, gerekçe + literatürden örnek paper)
  - (c) **Sample size + dataset/araç hint** (önerilen metod için)

Q1 = bilgisel sentez (lit özet); Q3 = eylem önerisi (metodoloji). Birlikte funnel'i tamamlar: keşif → sentez → eylem.

### Backend

**Yeni endpoint: `POST /api/q/method`**

Request:

```python
class QMethodRequest(BaseModel):
    model_config = ConfigDict(extra="forbid")
    query_id: str = Field(min_length=8, max_length=64)
```

Response:

```python
class QMethodResponse(BaseModel):
    model_config = ConfigDict(extra="forbid")
    query_id: str
    language: Literal["tr", "en", "id"]      # sorgu dili (Q'dan miras)
    sol_panel_papers: list[PaperCard]        # 3 kart, hem Anon hem Pro (Q1 ile aynı schema)
    paywall: bool                            # Anon → True, Pro → False
    distribution: list[MethodDistribution] | None    # Pro: 7 grup yüzde
    suggestions: list[MethodSuggestion] | None       # Pro: 2-3 öneri
    sample_hint: SampleHint | None                   # Pro
    used_paper_ids: list[str] | None                 # Pro: K=25 paper id

class MethodDistribution(BaseModel):
    model_config = ConfigDict(extra="forbid")
    method: Literal[
        "experimental_rct",
        "observational",
        "qualitative",
        "mixed_methods",
        "systematic_review",
        "simulation",
        "theoretical",
    ]
    method_label: str          # sorgu dilinde label, örn TR: "Deneysel / RCT", EN: "Experimental / RCT"
    percentage: float          # 0..100, sum ≈ 100
    paper_count: int           # bu metoda atanan paper sayısı (K=25 üzerinde)

class MethodSuggestion(BaseModel):
    model_config = ConfigDict(extra="forbid")
    method: Literal[7-tag]                 # MethodDistribution ile aynı 7 enum
    method_label: str                      # sorgu dilinde
    rationale_text: str = Field(min_length=40, max_length=500)   # neden bu metod, sorgu dilinde
    example_paper_id: str                  # ⊆ used_paper_ids zorunlu
    example_rank: int                      # 1..50 (sol panelle sync için)

class SampleHint(BaseModel):
    model_config = ConfigDict(extra="forbid")
    typical_sample_size: str               # serbest metin, sorgu dilinde, örn "n=200-500 (RCT literatürü)"
    datasets_or_tools: list[str]           # 2-5 madde, sorgu dilinde
```

`PaperCard` Q sayfası ile **aynı schema** (DM-047/052/055).

**Service:** `api/services/q_method_service.py` (yeni)

1. `query_id` ile Redis'ten Q havuzunu çağır: `q:search:{sha256(query)}:{lang}`. Miss → HTTP 410 Gone, frontend `/q`'a yönlendirir.
2. Tier check: cookie `pm_tier` → `"anon"` | `"pro"`.
3. **Anon path:**
   - Cache `q:method:{query_id}:anon` hit → return
   - `sol_panel_papers` = havuzdan rank 1..3
   - `paywall=True`, `distribution/suggestions/sample_hint/used_paper_ids = None`
   - Cache yaz, 24h TTL
4. **Pro path:**
   - Cache `q:method:{query_id}:pro` hit → return
   - **Rerank Aşama 1 (deterministic, DM-049 doktrini):** 50-paper havuzdan native skor → top-25 (`used_paper_ids`)
   - **Method Classification (LLM Pass 1):** Her paper için cache `q:method_classify:{paper_id}` kontrol → miss ise Gemini Flash 2.0 ile 7-tag sınıflandırma; batch 25 paper tek call (toplu prompt). Pydantic:
     ```python
     class ClassifyOutput(BaseModel):
         classifications: list[dict] = Field(min_length=25, max_length=25)
         # her dict: {paper_id: str, method: 7-tag, confidence: float}
     ```
   - **Distribution hesabı (deterministic):** 25 sınıflandırmadan yüzde + paper_count → `MethodDistribution` array (7 grup, 0% olanlar dahil).
   - **Suggestion + Sample hint (LLM Pass 2):** Tek call, sorguya göre 2-3 metod öneri + sample/dataset. Prompt sorgu diline göre seçilir:
     - `lang=="tr"` → "Aşağıdaki 25 makale ve sorgu için en uygun **2-3 metod** öner. Her öneri için: yöntem (7 enum'dan biri), gerekçe (40-500 karakter, **Türkçe**), literatürden örnek paper (paper_id used_paper_ids içinden), rank. Ayrıca önerilen ana yöntem için sample size aralığı + bilinen 2-5 dataset/araç (Türkçe)."
     - `lang=="en"` → "...suggest 2-3 most appropriate **methods**...rationale in **English** (40-500 chars)..."
     - `lang=="id"` → "...sarankan 2-3 metode...alasan dalam **Bahasa Indonesia**..."
   - **Pydantic structured output (citation grounding):**
     ```python
     class SuggestionOutput(BaseModel):
         suggestions: list[MethodSuggestion] = Field(min_length=2, max_length=3)
         sample_hint: SampleHint
         used_paper_ids: list[str] = Field(min_length=25, max_length=25)
     ```
   - **Validation kapısı:**
     - Her `suggestion.example_paper_id` ⊆ `used_paper_ids`
     - Her `suggestion.method` ∈ 7-tag enum
     - `distribution[*].percentage` toplam 99.5..100.5 aralığında (yuvarlama toleransı)
     - Reddedilirse 1 retry; ikinci ret → HTTP 502 + log
   - `sol_panel_papers` = havuzdan rank 1..3 (Anon ile aynı)
   - Cache yaz, 24h TTL

**LLM seçimi:**

- Pilot: tek model **Gemini Flash 2.0** (Q1 ile aynı, DM-049). 3 dil native destek. Method classification + suggestion 2 ayrı pass çünkü classification reusable cache.
- F2'de değerlendirme: Cosmos/Qwen/Sea-Lion ayrı stack vs tek Gemini.

**Diğer endpoint'ler:**

- `POST /api/waitlist` — Q ile aynı.
